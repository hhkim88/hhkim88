## 1. 프로젝트 개요

중장기 투자자를 위한 **AI Bull vs Bear 토론 시스템**. Claude API tool-use로
두 페르소나(강세론·약세론 애널리스트)가 같은 종목을 두고 3라운드 토론하고,
사회자(Moderator)가 "합리적 보수 투자자" 관점에서 종합 권고를 생성.

- **Layer 1** (`company_search/`): 자체 검색 백엔드 — 뉴스(KR/US), 재무
  (DART/yfinance), 시세(FinanceDataReader), 컨센서스, 유튜브 트랜스크립트,
  IR/SEC 공시, Reddit/종토방, Seeking Alpha, 어닝콜 등 12종 도구.
  SQLite 24h TTL 캐시.
- **Layer 2** (`debate/`): 토론 오케스트레이터 — Bull·Bear·Moderator 페르소나
  + 라운드 루프 + 마크다운 회의록 생성.
- **진입점**: `scripts/debate.py "<company>" --market US|KR --rounds 3 --output ...`

## 3. 설계 결정 이력 (왜 지금의 모습이 됐는가)

각 결정은 실제 테스트 결과의 문제를 보고 수정한 것. 시간순.

### 3-1. Anchoring 제거 (35/45/20 고정 → 기계적 표)
- **문제**: 초기 Moderator가 모든 종목에 비관 35% / 기본 45% / 낙관 20%를
  거의 그대로 출력. 종목 특성이 분포에 반영 안 됨.
- **해결**: C-1에 8행 기계적 가중치 표(베이스라인·PEG·사이클·모멘텀·성장
  가속·규제·컨센서스 쏠림·가격 위치)를 강제. 각 행 ±pp 명시 후 정규화.
- **검증**: GOOGL v2 케이스에서 "+5pp 합산해놓고 -10pp 결론"하는 산수 모순도
  C-2 자기검사 표로 차단됨.

### 3-2. 페르소나: "매우 보수" → "합리적 보수"
- **문제**: 안전마진 30% 풀 적용으로 모든 종목이 "진입 회피". 강세장에서
  작동 불가.
- **해결**: 종목 안정성에 따라 차등 안전마진 (안정 대형주 10~15%, 일반
  대형주 15~20%, 변동성·사이클 25~30%). 30% 풀마진은 1차 진입이 아니라
  분할 매수 후반 단계로 분리.
- **유지 조건**: "낙관이 비관을 상회해야(G>0) 어떤 형태든 매수 권고 가능"
  (사용자 명시).

### 3-3. 베이스라인 분포 + 휴리스틱 재밸런스 (B + X + Y)
- **문제**: 매트릭스 수정 후에도 5개 테스트 종목이 전부 회피·보유로 수렴.
  베이스라인 자체가 비관 편향.
- **해결**: 베이스라인 30/45/25 → 25/45/30, 성장 가속 행 추가, 컨센서스/
  가격위치 가중치 감소.

### 3-4. 모델 스왑 시도 → 일부 롤백 (a+b+e → a+b)
- **시도**: 토론 30분→15분 단축 위해 Round 1 병렬화(a) + 도구 캐싱(b) +
  Haiku 모델 스왑(e).
- **문제**: Haiku는 인용 환각률 82% (LLY 케이스에서 Reuters/Reddit 가짜
  인용). 동시에 Sonnet의 Moderator 출력 truncation 발견.
- **해결**: e만 롤백 (Bull/Bear/Moderator 모두 Sonnet). a·b는 유지. 출력
  truncation은 `_agent_run`이 `ResultMessage.result` 단일 필드만 읽던 것을
  `AssistantMessage`의 `TextBlock`들을 누적 합치도록 수정.
- **현재 상태**: `DEBATE_MODEL`·`MODERATOR_MODEL` 모두 `claude-sonnet-4-6`
  기본값 (환경변수로 오버라이드 가능).

### 3-5. P/E 절대값 → PEG 밴드 (Option B)
- **문제**: 고P/E 종목이 구조적으로 불리. NVDA(P/E 60+) → 회피로 수렴.
- **해결**: 밸류에이션 행을 PEG 4밴드로 교체. PEG ≤ 1.0 (-5/+10), 1.0~2.0
  (0/0), 2.0~3.5 (+5/-5), >3.5 (+10~15/-8~-10). 사이클·적자·성장률 미공개
  케이스는 동종 P/E 비교 fallback.
- **검증**: NVDA G가 -회피→+신규매수로 플립, KO PEG 1.60 → 0/0 (방어주
  공정 처리).

### 3-6. 시나리오 표 인용 출처 컬럼 (a안)
- **문제**: PLTR의 비관 시나리오 $95 목표가 Bull/Bear 누구도 명시 안 한
  사회자 추론이었음.
- **해결**: C-3 시나리오 표에 "인용 출처" 컬럼 추가. 4단계 우선순위:
  ① Bull/Bear 명시 구체 목표가, ② 컨센서스 분위 수치, ③ 52주 고/저, ④
  사회자 추론(근거 명시). 3개 중 2개 이상이 ④면 ⚠️ 경고문 자동 삽입.

### 3-7. TL;DR 최상단 재구성 (가독성)
- 권고·G·현재가 평가·6개월 목표가·핵심 강세 한줄·핵심 약세 한줄·결정
  트리거를 박스 형태로 섹션 0에 배치. 상세 분석은 섹션 2로 후순위.

### 3-8. 매트릭스 vs C-2 정합성 충돌 해소 (커밋 `cf0984d`)
- **문제**: 매트릭스가 "G=0~+5pp & -5%초과 → 보유"인데 C-2 정합성은
  "분할 매수 → G≥0pp"라고 해서 LLM이 "구조적 강세 사이클 보정"으로
  override (1차 ETN G=+1pp 케이스).
- **해결**: 매트릭스에 행 추가 — G=0~+5pp & 가격 -5%~-10%이내 → 분할매수
  (보수적). G=0~+5pp & -10%초과 → 보유. C-2도 같은 granularity로 정밀화.
  override 금지 명시 조항 추가.

### 3-9. 티커 해석 버그 수정 (커밋 `40cfa2c`)
- **문제**: `get_financials` US 경로가 회사명을 yfinance에 그대로 전달
  ("Eaton" → "EATON" 심볼 조회 → HTTP 404). 재무 누락이 PEG 못 계산되게
  해 1차 ETN이 G=+1pp로 왜곡됨.
- **해결**: `debate/tools.py`에서 `ticker.resolve(company, market="US")`
  먼저 호출 후 그 결과를 yfinance에 전달. 재실행 ETN → G=+34pp로 정상화.

### 3-10. PEG 분모 평균화 (커밋 `11537e0`)
- **문제**: ETN의 PEG 분모 "53.8% 성장률"이 사실은 (Forward EPS / Trailing
  EPS − 1) 단일 연도 점프. 일회성 컨센서스 추정으로 PEG가 휘둘림.
  사회자가 2-6 핵심 질문에서 이 가정을 핵심 리스크로 지적했으면서 C-1
  표에서는 가정을 사실로 취급해 만점 보너스 부여 → 내부 모순.
- **해결**: PEG 분모 = ① Forward-implied 1년 성장률과 ② 실현 2~3년 CAGR의
  **산술 평균**. C-2에 세 숫자 모두 명시 강제. 단일 forward 점프 사용 금지.
- **검증**: META 케이스에서 ① 52% + ② 42.5% → 평균 47% → PEG 0.36으로
  깨끗하게 작동. Bull의 (Q1 단일분기 매출 33% 사용한) PEG 0.52를 사회자가
  명시적으로 정정함.

## 4. 미해결 이슈

### 4-1. 인용 검증 시스템의 키워드 사각지대 (META 케이스 노출)
- 현재 검증: `source_name`/`URL`이 풀에 있는 항목과 일치하는가만 확인.
- 빠진 검증: "그 기사가 실제로 그 주장을 담고 있는가"는 확인 못 함.
- META 케이스: Bear가 "JPMorgan downgrade to Neutral" 주장. 매칭된 풀
  항목은 "BofA Trims..." 기사 — JPMorgan 다운그레이드 기사가 아님. 그러나
  Bear가 "24/7 Wall St." source를 지정해서 ✅ verified로 찍힘. 핵심 논쟁점이
  미결로 남음.
- **고민 방향**: 인용된 주장의 키워드(예: "JPMorgan", "downgrade")가 매칭
  기사 제목에 포함되는지 추가 체크. 트레이드오프 — 거짓 양성 증가 가능.

### 4-2. PEG 평균에서 ②CAGR 산출이 어려운 경우
- META는 EPS 추이 데이터 부족해서 영업이익 CAGR로 대리. 현재 규칙은 "②
  산출 불가 → PEG 적용 불가 fallback"이지만 사회자가 자율적으로 대리
  지표를 쓰는 케이스가 발생. 명시화 필요할 수도.

### 4-3. 빅테크 고성장주 상위 쏠림이 정당한가
- 매트릭스 상위 5개 중 4개가 빅테크/고성장(PLTR·META·NVDA·GOOGL) +
  데이터센터 산업재(ETN·VRT). 프레임워크가 진짜 alpha를 잡는 건가, 아니면
  컨센서스 follower라서 결국 시장 평균 따라가는 건가? — 5번 항목 검증
  필요.

## 5. 검증 로드맵 (production 전 필수)

### 5-1. 백테스트 — 최우선
- **함정**: Sonnet 4.6 훈련 컷오프(2025-08) 이전 시점은 데이터 누설로
  cheating 가능. 모델이 미래를 알고 추론.
- **안전 윈도**: 현재 시점(2026-05) 이후 미래 데이터로만.
- **측정**: Hit rate (양의 수익률 비율), G ranking spread (G+30 vs G-30
  종목들 수익률 격차), 시나리오 확률 Brier score.

### 5-2. 재현성 (Reproducibility)
- 같은 종목 5회 실행 → G 표준편차, 권고 일치율.
- 기준: G ±5pp 이내, 권고 일치 80%+.
- 후보 종목: NVDA(강세 고확신), V(약세 고확신), COST(중립 경계).
- 못 넘으면 ensemble(3~5회 평균) 강제.

### 5-3. 단순 베이스라인 대비 우위
- 비교군:
  - (a) 컨센서스 평균이 현재가 대비 +20%+ → 매수
  - (b) Forward P/E <20 + EPS YoY >+15% → 매수
  - (c) S&P500 시총가중 보유
- 지금 18개 종목 권고를 (a)와 비교: 일치율이 너무 높으면 프레임워크는
  비싼 컨센서스 follower일 뿐.

### 5-4. Adversarial 케이스
- Luckin Coffee 사기 발각 직전, BBBY 파산 직전, AT&T 배당컷 직전,
  Wirecard 사기 발각 직전 같은 케이스에서 사회자가 위험 신호 잡는가.

### 5-5. 저커버리지 종목
- 외부 인용 풀 5건 미만 소형주 → false confidence vs honest uncertainty
  중 어떻게 행동하는가.

### 5-6. 섹터 한계
- PEG 안 통하는 케이스 매트릭스화 필요:
  - 금융주: P/B·NIM·credit losses
  - REIT: AFFO
  - 바이오: 파이프라인 NPV
  - 자원·사이클: 상품가격 dominant
- 현재 fallback("동종 평균 P/E 비교")로는 부족할 가능성.

## 6. Paper Portfolio 트래킹 셋업 (제일 먼저 할 일)

새 세션이 첫 작업으로 이걸 하는 게 효율적.

### 셋업
- **시작일**: 2026-05-15 (오늘)
- **종료일**: 2026-11-15 (6개월 후)
- **벤치마크**: S&P500 동일가중 (KR 종목은 KOSPI 비중)
- **포지션 룰**:
  - G ≥ +15 → 100% 진입 (신규매수)
  - G = 0 ~ +15 → 50% 진입 (분할매수)
  - G < 0 → 0% (보유/회피)
- **종목별 비중**: 균등 (단순화). 정밀화 원하면 G 비례 가중.

### 측정 지표
- Portfolio 6개월 수익률 vs benchmark (alpha)
- Hit rate: 매수 권고 중 양의 수익률 비율
- Max drawdown
- G ranking spread: 상위 5개 종목 평균 수익률 − 하위 5개 평균
- 시나리오 확률 calibration: 비관 N%로 매긴 종목들 중 실제 비관 영역에
  N% 안착했는가

### 파일 위치 제안
- `portfolio/paper_track_2026Q2.csv`: 컬럼 = 종목·G·권고·진입가·진입일·
  벤치마크값·6개월후가·6개월후벤치마크·수익률·alpha
- `portfolio/README.md`: 룰 명시·재현 방법
