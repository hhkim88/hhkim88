# daybeat 🎧

하루종일 녹음한 소리로 그날의 비트를 만드는 프로젝트입니다. 이 단계는 그 앞에 붙는 **프라이버시 필터**입니다.

## 프라이버시 필터: 내가 참여한 대화만 남긴다

```
하루 녹음 ─▶ VAD(말소리 찾기) ─▶ 대화 단위로 묶기(15초 이상 침묵 = 다른 대화)
           ─▶ 대화마다 내 목소리 프로필과 비교
               ├─ 내가 2초 이상 말함 → 보관   out/conversations/conv_HHMMSS.flac
               └─ 아니면            → 삭제   (파일을 아예 쓰지 않음)
           ─▶ 모든 대화 구간을 무음 처리한 생활 소음 → out/ambient.flac (비트 재료)
           ─▶ 판정 로그(시간·수치만, 내용 없음)  → out/privacy_log.json
```

**판단이 애매하면 삭제**합니다.
- 듣기만 하고 말하지 않은 대화("응" 같은 짧은 맞장구만 한 경우 포함)는 삭제합니다.
- 화자 모델 오류로 판정하지 못한 대화도 삭제합니다.
- 보관한 대화도 `ambient.flac`에서는 지워지므로, 비트에는 **사람 말소리가 들어가지 않습니다**.

## 사용법

```bash
pip install -r requirements.txt   # ffmpeg도 필요 (m4a 등 변환용)

# 1) 내 목소리 등록: 조용한 곳과 시끄러운 곳에서 각각 30초 이상 녹음
python -m daybeat enroll my_voice_quiet.m4a my_voice_street.m4a -o me.npy

# 2) 하루 녹음 필터링
python -m daybeat filter day.m4a --profile me.npy -o out/ --start 08:00 --delete-input
```

출력 예시:
```
대화 3건 중 보관 1건, 삭제 2건
  [보관] 091204    184.3s  내 발화  61.6s  최대유사도 0.874
  [삭제] 123010     45.0s  내 발화   0.0s  최대유사도 0.612
  [삭제] 183522     12.1s  내 발화   0.8s  최대유사도 0.771
```

### 튜닝
| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--threshold` | 0.75 | 내 목소리로 판정할 유사도 기준. 로그의 `max_similarity`를 보고 조정 |
| `--min-user-seconds` | 2.0 | 참여로 인정할 최소 발화 시간 |
| `--conversation-gap` | 15 | 이 시간(초) 이상 침묵하면 다른 대화로 나눔 |

## 주의
- **법적 판단은 아닙니다.** 대화 당사자의 녹음은 통신비밀보호법상 일반적으로 허용되지만, 보관한 대화에는 상대방 목소리도 들어 있습니다. 공유하거나 공개하면 음성권·개인정보 문제가 생길 수 있으니 본인만 보관하세요.
- 서버에서 필터링하면 **필터링 전 원본이 잠시 서버에 존재**합니다. 최종적으로는 폰에서 녹음과 동시에 필터링하는 구조가 가장 안전합니다. `--delete-input`을 쓰고, 폰에 남은 원본도 지우세요.
- 화자 인식은 100% 정확하지 않습니다. 목소리가 비슷한 사람, 소음이 심한 환경, 전화 통화(상대 음성이 스피커로 나오는 경우)에서는 오판할 수 있습니다.
